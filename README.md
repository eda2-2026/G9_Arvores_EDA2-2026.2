# G9_Arvores_EDA2-2026.2

# 🌿 Sprout AVL

> Um jogo web interativo educativo focado no aprendizado prático de **Árvores AVL** (Árvores Binárias de Busca Auto-balanceadas), desenvolvido para a disciplina de Estruturas de Dados e Algoritmos 2 (EDA2) na Universidade de Brasília (UnB).

---

## 🎯 Sobre o Projeto

O **Sprout AVL** transforma conceitos teóricos de estruturas de dados avançadas em uma experiência gamificada. O objetivo do jogador é "cultivar" uma árvore digital equilibrada através de inserções e missões dinâmicas, compreendendo em tempo real como o **fator de balanceamento** e as **rotações** (`LL`, `RR`, `LR`, `RL`) atuam para manter a altura da árvore otimizada ($O(\log n)$).

---

## 🚀 Funcionalidades

* **Árvore AVL em Tempo Real:** Inserção de nós com cálculo automático de altura e fator de balanceamento para cada elemento.
* **Detecção e Execução de Rotações:** Visualização interativa das quatro rotações clássicas de balanceamento quando o fator de equilíbrio excede os limites de tolerância ($\{-1, 0, +1\}$).
* **Modo Jogo / Missões:** Desafios progressivos que exigem que o usuário atinja estados específicos na árvore para avançar.
* **Renderização via Canvas:** Interface limpa e responsiva construída com HTML5 Canvas e JavaScript puro, sem dependências complexas.
